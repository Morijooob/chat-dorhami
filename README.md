# چت دورهمی — نسخه 2 آنلاین

نسخه‌ای آماده برای Deploy روی اینترنت: ثبت‌نام/ورود، چت خصوصی، اتاق عمومی «دورهمی»، Real-time با Socket.IO، ذخیره پیام در SQLite، Helmet و Rate Limit پایه.

## اجرا در سرور
Node.js 20+ لازم است.

```bash
npm install
JWT_SECRET="یک-کلید-تصادفی-حداقل-۳۲-کاراکتری" npm start
```

برای هاست ابری، متغیرهای محیطی `JWT_SECRET` و در صورت نیاز `DB_PATH` را تنظیم کنید. برای SQLite حتماً از دیسک/Volume دائمی استفاده کنید؛ روی فایل‌سیستم موقت، با Restart/Deploy ممکن است داده‌ها از بین بروند.

## نقشه درآمد
این نسخه از ابتدا برای توسعه این مدل‌ها طراحی شده: تبلیغات، اتاق‌های ویژه، اشتراک VIP، نشان تأیید، بوست پروفایل، فروش جایگاه تبلیغاتی، امکانات پولی برای سازندگان اتاق و هدیه/سکه مجازی. پرداخت واقعی درگاه و سیستم کیف پول باید بعد از اعتبارسنجی بازار اضافه شود.

## انتشار عمومی
HTTPS، Secret قوی، بکاپ دیتابیس، لاگ/مانیتورینگ و محدودیت‌های ضداسپم قبل از جذب کاربر زیاد الزامی‌اند.
