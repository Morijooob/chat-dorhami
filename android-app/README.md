# اپ اندروید دورهمی

این پوشه مربوط به اپ اندرویدی دورهمی است و از کد سایت اصلی جدا نگه داشته می‌شود.

## مرحله فعلی
اسکلت اولیه اپ مشخص شده است. اپ در نسخه اولیه، سایت موجود دورهمی را داخل WebView نمایش می‌دهد و هیچ API، دیتابیس یا کد سایت اصلی را تغییر نمی‌دهد.

## آدرس سایت
https://chat-dorhami.m73216r.workers.dev/

## اصل مهم
توسعه اپ فقط روی شاخه `app-development` انجام می‌شود. تا زمان تأیید صریح، هیچ تغییری روی `main` اعمال نمی‌شود.

## مراحل بعدی
1. ایجاد پروژه Android مستقل
2. WebView امن و تمام‌صفحه
3. مدیریت دکمه Back اندروید
4. مدیریت خطای اتصال
5. تست ورود، ثبت‌نام و چت
6. آماده‌سازی نسخه انتشار
